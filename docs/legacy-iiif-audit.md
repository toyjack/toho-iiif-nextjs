# 旧站公开书目与 IIIF 图像核对（2026-11-12）

对照旧站 `http://kanji.zinbun.kyoto-u.ac.jp/db-machine/toho/html/top.html`（及其下的十三經注疏、寶卷五十種子目录）与本库 `data/books/`，检查旧站公开的书是否都有 IIIF 图像（`https://image.kanji.zinbun.kyoto-u.ac.jp/toho/iiif/<前缀>%2F<前缀>NNNN/info.json`）。

## 方法

- 旧站「公开」：首页（含子目录页）中未被 HTML 注释掉的书目链接，共 442 个 ID。注释掉的有 C050（札樸）与 M074（白花道場發願文略解，首页改链 M090）。
- 对本库没有的 ID 和本库 `available: false` 的书，逐个抓取目录页与卷页面，读取 `bookNum`、`volStartPos`、`volMaxPage`，按图像前缀（`bookNum`）分组，请求每组首、末图像的 `info.json`；并确认旧站 `S/` 下的首张 JPEG 存在（全部 200）。
- 本库 `available: true` 的 307 部已由 `fetch-image-sizes` 读取过 `info.json`，未重复检查。
- 只查首、末两张；中间个别图像缺失不在本次范围内。请求逐个发送并间隔等待。

## 二、IIIF 图像已有，但本库没有对应书目

**已补入（2026-11-12）**，共 55 部，图像只用本书 ID 一个前缀：

- 經部：A004–A013（十三經注疏子目，出版事项沿用 SJ000）、A051、A065–A074
- 史部：B167–B174、B176–B180、B182
- 子部：C027、C033、C036、C039、C051–C059
- 集部：D164–D169
- 日本書：W001（新增分类，旧站首页的分类标题；加入 `data/site.yaml`）

补入方式：书名、出版事项、分类取自旧站首页（或十三經注疏子目录页）；卷册结构取自目录页（含二级目录）的链接文字和各卷页面的 `volStartPos`、`volMaxPage`；`imageSize` 由 `fetch-image-sizes` 读取（A013 末张为竖幅，列入 `data/image-sizes/A013.tsv`）。著者、時代未录入；`bookType` 只在出版事项明写「刊本／印本／鈔本」等时填写，其余为 `unknown`；书名含「殘」「闕」时 `isIncomplete: true`。各书正文的「数据修订」一节记录来源。

对照实际图像修正了旧站卷页面的三处 `volMaxPage`（详见各书「数据修订」）：A007 卷第四十二（6→46）、A004 A0040029（并入册末空白页与封底）、A006 A0060038（并入封底）。

**未补入**：

- D101A–D149A（寶卷五十種的子目）：每种分上下卷，图像前缀不同（如 D101A、D101B），现有数据模型一书只用一个前缀，需要先决定模型（见第三节）。
- M090：旧站首页以它替代本库已有的 M074（同名「白花道場發願文略解」，同为 14 张，图像尺寸约差 1%，似为同一书的重扫）。需确认后再决定改用 M090 的图像或保持现状。
